# Eric Anthony — Senior Backend & Distributed Systems Engineer Portfolio (v2)

A brand new, high-agency personal portfolio website engineered with an industrial dark minimalism aesthetic, electric cyber cyan telemetry accents, and live interactive distributed architecture visualizations.

## Key Highlights & Design Innovations
- **Aesthetic Direction**: High-agency dark obsidian (`#08090b`) canvas with electric cyan (`#00f0ff`) accents, hairline borders, and mechanical telemetry indicators.
- **Copywriting**: High-authority, quantified engineering narratives highlighting real production milestones (GoPay digital insurance SDUI latency reduction, 80% Redis cost optimization at Noice, 1Engage enterprise WhatsApp broadcasting & WebRTC).
- **Interactive Live Topology Visualizer**: Custom Canvas 2D interactive distributed microservices simulator with data packet streams, node inspection, and dependency bursts.
- **Dynamic Stack Matrix**: Interactive filtering across Core Languages, Distributed Systems, Databases & Caching, and Cloud/DevOps.
- **Performance & a11y**: Zero heavy frontend frameworks, native CSS Grid, full WCAG AA contrast compliance, keyboard accessibility with skip-links, and full `prefers-reduced-motion` fallbacks.
- **PWA Ready**: Complete offline support and installable web app manifest.
